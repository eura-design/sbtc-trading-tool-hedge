#########################################################
# 1. 화면과 바이낸스의 관계
#########################################################

포지션 / 익절 / 손절 / 추가진입 / 분할TP / 잔고
  -> 전부 바이낸스에 조회해서 그대로 보여준다.
     우리가 만들어낸 가짜는 없다.

갱신 주기: 3초(계정 감시) / 30초(화면) / 60초(정합성 검사)


-- 일부러 안 보여주는 것 --------------------------------

  지정가 주문에 미리 걸어둔 익절·손절
    거래소엔 있지만 체결 전까지 숨긴다.
    플랜 박스가 같은 가격을 이미 보여주기 때문.
    체결되면 그때 나타난다.


-- 못 보여주는 것  ** 중요 ** ---------------------------

  트레일링 스톱
    개념 자체가 없다. 거래소엔 있는데 화면엔 안 뜬다.
    "있는 걸 없다고 보여주는" 유일한 경우다.
    -> 밖에서 쓰지 말 것.

  BTC 외 코인
    시스템이 BTCUSDT만 본다.
    다른 코인은 포지션도 주문도 아무것도 안 뜬다.

  같은 방향에 진입 대기 주문이 2개 이상이면 하나만 뜬다.


-- 플랜 박스는 주문이 아니다 ----------------------------

  차트의 박스는 "내가 그린 계획"이다.
  주문을 내면 익절·손절이 같이 등록되지만,
  익절이 거절되면(현재가 안쪽일 때) 박스엔 선이 있는데
  거래소엔 없는 상태가 된다.
  -> 그때는 주문 직후 경고 문구가 뜬다. 그게 신호다.


#########################################################
# 2. 백엔드를 꺼도 되나
#########################################################

먼저: 바이낸스에 올라간 주문은 우리 시스템과 무관하게 산다.
      컴퓨터를 꺼도 가격이 닿으면 발동한다.

백엔드가 하는 일은 딱 하나 —
  "포지션이 청산되면 남은 추가진입 주문을 취소해준다"
  (2026-08-23부터 손절은 주문할 때 미리 같이 걸린다)


  포지션도 주문도 없다            -> 꺼도 된다
  포지션만 있다                   -> 꺼도 된다
  지정가를 걸어뒀다               -> 대체로 꺼도 된다 *
  포지션 + 추가진입 주문이 있다   -> 켜두는 게 좋다 **


  *  주문 낼 때 "손절 등록 실패" 경고가 떴다면 예외.
     그때는 켜둬야 한다.

     익절은 안 걸릴 수 있다 (돈 잃는 문제는 아님):
       익절이 "진입가와 현재가 사이"에 있으면
       바이낸스가 거절한다.
         예) 현재 76,000 / 익절 75,000 / 진입 72,000
       손절은 정상적으로 걸린다.
       익절은 체결될 때 다시 걸린다(백엔드가 켜져 있으면).

  ** 손절이 발동해 포지션이 사라져도
     추가진입 주문은 그대로 남는다.
     나중에 그 가격에 닿으면 손절도 없는 새 포지션이
     혼자 열린다.
     백엔드가 켜져 있으면 청산 즉시 취소해준다.


-- 나도 모르게 꺼지는 경로 ------------------------------

  [1] 윈도우 자동 업데이트   <- 가장 현실적인 위험
      밤에 재시작되면 아침까지 꺼진 채로 있다.
      start.bat 은 자동으로 안 켜진다.
      대책: 활성 시간을 넓게 잡거나, 업데이트 일시 중지.

  [2] 절전 모드
      화면이 꺼지는 것과 절전은 다르다.
        화면 꺼짐 = 모니터만 꺼짐. 문제 없다.
        절전     = 컴퓨터가 멈춘다. 위험하다.
      현재 이 PC: 절전 "안 함" / 화면 끄기 15분  -> 안전.
      전원 설정을 건드리면 이걸 다시 확인할 것.
      노트북이면 뚜껑 닫을 때 절전으로 들어간다.


-- 재시작할 때 --------------------------------------------

  node.exe 를 **전부** 종료하고 start.bat 을 실행한다.
  포트만 보고 죽이면 하나가 살아남아 두 개가 동시에 돈다.
  (2026-08-23에 실제로 그랬다 — 같은 계좌를 두 프로세스가
   만지고 파일을 서로 덮어썼다)

# 3. 밖에서 매매할 때
#########################################################

  하지 말 것
    - 트레일링 스톱   (화면에 안 뜬다)
    - BTC 외 코인     (아무것도 안 뜬다)

  할 것
    - 바이낸스 "웹"에서 익절·손절을 같이 걸어 주문한다.
      (앱에는 그 기능이 없다)
      체결 시 바이낸스가 알아서 손절을 건다.
      브라우저를 닫아도, 백엔드가 꺼져 있어도 안전하다.
      단, 체결 전까지는 우리 화면에 그 값이 안 보인다.

  밖에서 낸 지정가·추가진입·분할익절은
  집에 와서 화면을 켜면 전부 정상적으로 뜬다.
  차트에서 드래그로 옮기고 x 로 지울 수도 있다.

#########################################################
# 5. 매일 확인
#########################################################

  [ ] 주문 낼 때 경고 문구가 떴는가 (손절 등록 실패)
  [ ] 포지션이 있다면 손절이 걸려 있는가
  [ ] 추가진입 주문이 있다면 백엔드가 켜져 있는가
  [ ] 밤사이 재시작된 적은 없는가

  화면(브라우저)은 꺼도 된다. 백엔드만 살아있으면 된다.

  이상하면:  http://localhost:3002/api/health
             account.changes 가 안 올라가면 감시가 죽은 것
